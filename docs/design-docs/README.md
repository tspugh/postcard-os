# Design prototypes

This directory contains static interface explorations created during the product design process. The businesses, people, contact details, campaign events, prices, claims, and outreach messages in these fixtures are fictional and exist only to demonstrate workflow states. Domain names used for fictional businesses are under the reserved `.example` top-level domain.

The prototypes are not a production data source and are not imported by the application. Open the standalone HTML files directly to inspect the earlier interface concepts; the maintained React application lives in `web/`.
